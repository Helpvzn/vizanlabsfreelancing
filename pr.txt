# MASTER PROMPT — FREE FREELANCE PROJECT MARKETPLACE

You are a senior full-stack architect and developer.

I want you to build a production-ready MVP of a freelance marketplace platform similar in concept to Upwork, Fiverr, and Freelancer, but with a different business model:

**Clients can post freelance projects/jobs for FREE.
Freelancers can create accounts, browse projects, and submit proposals for FREE.**

The initial platform should avoid unnecessary paid services and should be designed to run primarily on Cloudflare's free/low-cost infrastructure.

Do NOT copy the UI, branding, text, or proprietary design of Upwork, Fiverr, or Freelancer. Build an original product and UI inspired only by the general concept of a freelance marketplace.

---

# 2. MAIN DIFFERENTIATOR

The platform should initially be positioned as:

"Post projects for free. Find freelance opportunities for free."

Do NOT force users to pay to:

* Create an account
* Post a project
* Browse projects
* Create a freelancer profile
* Submit normal proposals
* Send normal messages

The platform should be designed so monetization can be added later.

Possible future monetization:

* Featured projects
* Featured freelancer profiles
* Premium visibility
* Verified profiles
* Optional commission
* Premium memberships
* Sponsored listings

Do not implement complex payments in the first MVP unless specifically requested later.
